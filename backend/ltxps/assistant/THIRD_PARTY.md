# Third-party material in the assistant

- **themes.json** (145 design themes): colours, fonts and descriptions were distilled from the `design-systems/*/tokens.css` files of **Open Design** (https://github.com/nexu-io/open-design, Apache License 2.0). Generated by `backend/tools/build_theme_catalog.py`. Brand names in theme titles are trademarks of their owners; the themes are style references and imply no affiliation or endorsement.
- **free-claude-code** (AGPL-3.0): not included. The assistant can talk to a copy you run yourself over HTTP (Anthropic-style API on port 8082 by default).
- Python libraries (installed from PyPI, see `requirements-assistant.txt`): FastAPI, Starlette, Uvicorn, Pydantic, httpx, Pillow, pypdf, python-docx, python-pptx, openpyxl, ReportLab. Each has its own licence.
